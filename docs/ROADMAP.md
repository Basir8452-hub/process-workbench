## 2. 已知问题

### 功能与体验

- 应用完全退出时不会后台推送；9:00 自动日报依赖应用运行，或在 9:00 后首次启动时补生成。
- 资讯默认使用必应资讯 RSS。若公司网络限制必应，需要在“资讯设置”中替换 RSS 源。
- 没有配置 AI 模型时，资讯只能生成原文摘要，无法生成分类摘要和 RAG 问答。
- 多人共用同一个 Windows 账号时，会共享同一份数据文件。

### 工程与发布

- 安装包未做代码签名，Windows SmartScreen 可能提示。
- 没有自动更新机制。
- Ant Design 6 的 `List` 组件存在弃用警告，不影响功能。
- 开发模式有 Electron CSP 安全警告。
- 历史打包目录 `release-v2` 到 `release-v7` 较多，交接前应清理，只保留最新产物或全部移出仓库。

## 3. 待办改进清单（均为用户提出）

### 下个版本（v0.5.3）：v0.5.2 缺陷修复

- **知识库卡片长标题被遮挡**：v0.5.2 把标题移入卡片头部后，antd 头部默认单行截断，标题不能换行，长标题被 `...` 遮挡。修复方向：让头部标题允许多行换行（`white-space: normal` + 行数限制），与三点按钮并列不变。
- **待办完成动画没生效**：v0.5.2 的完成动画有两处缺陷——①“右滑消失”用了 CSS `transform` 位移，但浏览器规范不允许表格单元格（td）做位移，右滑效果根本没发生；②“渐变变绿”只有 0.45 秒、颜色偏浅，一闪而过不明显。修复方向：改用“绿色从左到右扫过整行（伪元素宽度展开）+ 行内容右滑淡出”的醒目动画，时长加长到约 0.8 秒。

### 体验改进（未定版本）

- 文件台账改为“归档”定位：当前是“审核”型设计（含工序/产线/复审日期），改为归档型，方便检索；去掉工序/产线字段，换成标签；去掉生效时间和复审时间字段（有需要再加）。
- 个人知识库条目内容多格式共存：单条知识卡片支持文字、图片、表格等多种格式同时存在（不是扩充导入类型，而是同一卡片内多格式混排）。

## 4. 工程纪律（交接约定，非需求）

- 不要在未加测试的情况下大规模重构 `AppStore` 和 RAG Prompt 逻辑。
- 不要把 AI Key 写入源码或提交到 Git。
- 不要在未确认需求前引入多人协同和云端数据库。
- 不要直接删除用户数据文件或旧备份。
