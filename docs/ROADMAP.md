## 2. 已知问题

### 功能与体验

- 应用完全退出时不会后台推送；9:00 自动日报依赖应用运行，或在 9:00 后首次启动时补生成。
- 资讯默认使用必应资讯 RSS。若公司网络限制必应，需要在“资讯设置”中替换 RSS 源。
- 没有配置 AI 模型时，资讯只能生成原文摘要，无法生成分类摘要和 RAG 问答。
- 多人共用同一个 Windows 账号时，会共享同一份数据文件。

### 工程与发布

- 安装包未做代码签名，Windows SmartScreen 可能提示。
- 没有自动更新机制。
- Ant Design 6 的 `List` 组件存在弃用警告，不影响功能。
- 开发模式有 Electron CSP 安全警告。
- 历史打包目录 `release-v2` 到 `release-v7` 较多，交接前应清理，只保留最新产物或全部移出仓库。

- **后台推送依赖应用运行**：应用完全退出时不会推送；9:00 自动日报依赖应用运行，或在 9:00 后首次启动时补生成。候选方向：常驻后台 / 系统托盘 / 开机自启。
- **资讯 RSS 源单一**：默认使用必应资讯 RSS，公司网络若限制必应需在「资讯设置」中手动替换源。候选方向：内置多源 + 失败自动切换。
- **安装包未代码签名**：Windows SmartScreen 可能弹出安全提示。候选方向：代码签名证书（需成本 / 企业证书）。
- **无自动更新机制**：新版本需手动下载安装。候选方向：GitHub Releases 检查 + 更新提示 / 自动下载。
- **多用户数据隔离**：多人共用同一 Windows 账号时共享同一份数据文件。候选方向：按 Windows 用户目录隔离 / 多 Profile。
